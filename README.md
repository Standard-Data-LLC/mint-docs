# Standard Data docs

Mintlify source for Standard Data task-format and GDPx documentation.

## Pages

- `gdpx/quickstart.mdx`: GDPx task format and delivery-layer overview
- `gdpx/workflow.mdx`: GDPx interfaces, responsibilities, and technical-versus-program status
- `gdpx/benchmark-task-rubric-best-practices.mdx`: GDPx task design, grading, packaging, and calibration
- `gdpx/benchmark-task-package.mdx`: partner source handoff versus canonical v3 packaging
- `gdpx/benchmark-task-delivery.mdx`: partner responsibilities and the four program review stages
- `qc-stages-for-benchmark.mdx`: canonical QC stage definitions and evidence requirements
- `gdpx/benchmark-rollout-analysis.mdx`: one-rollout failure classification API
- `gdpx/evaluation-bundle-upload.mdx`: v3 task-and-evidence and active-catalog API
- `gdpx/rollout-viewer-evidence.mdx`: required evidence for the Wilderness Results view
- `gdpx/audit-endpoint.mdx`: audit API reference
