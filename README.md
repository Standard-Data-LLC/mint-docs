# Standard Data docs

Mintlify source for Standard Data task-format and GDPx documentation.

## Pages

- `gdpx/quickstart.mdx`: RL and benchmark task taxonomy
- `gdpx/workflow.mdx`: GDPx lifecycle, supported interfaces, and actor responsibilities
- `gdpx/benchmark-task-rubric-best-practices.mdx`: GDPx task design, grading, packaging, and calibration
- `qc-stages-for-benchmark.mdx`: QC stages and rollout-analysis integration
- `gdpx/benchmark-rollout-analysis.mdx`: one-rollout failure classification API
- `gdpx/evaluation-bundle-upload.mdx`: v3 task-and-evidence publication API
- `gdpx/rollout-viewer-evidence.mdx`: required evidence for the Wilderness Master view
- `gdpx/audit-endpoint.mdx`: audit API reference
