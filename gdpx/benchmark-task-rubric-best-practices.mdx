GDPx measures whether a model can finish representative, economically useful knowledge work in a realistic environment. The unit is the whole job: kickoff, source material, tools, observable work, final artifact, deterministic checks, and rubric.

<Info>
  GDPx does not use one universal pass-rate band. Core items should separate the models in the written evaluation plan, while easier items may serve as anchors. A zero-pass task can stay only if it is demonstrably solvable, the verifier works, and criterion-level results still provide useful signal.
</Info>

## Use this section

This guidance is split into four short pages so you can find the requirement you need without scanning one long document.

- [Design and grade](/gdpx/benchmark-task-design): define the work, build the environment, and make the rubric observable.
- [Package the task](/gdpx/benchmark-task-package): assemble the Harbor task, task taxonomy, ZIP, and self-contained environment.
- [Evaluate and analyze](/gdpx/benchmark-task-evaluation): run acceptance checks, analyze failures, and document reward integrity.
- [Partner delivery and review](/gdpx/benchmark-task-delivery): run the required partner evaluation and prepare the final handoff.

## GDPx standardized task bundle

The [Harbor task](/gdpx/quickstart#the-runnable-task) is the portable runtime core. The source-handoff and canonical-submission formats are separate; both are explained on [Package the task](/gdpx/benchmark-task-package).
