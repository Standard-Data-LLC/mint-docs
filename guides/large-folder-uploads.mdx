A GDPx task folder can include large datasets, images, CAD files, and run artifacts. Keep them with the task and attempt they belong to; do not flatten or convert them to make the folder look smaller.

## Check what you actually have

| What you find | What to do |
| --- | --- |
| Native file | Preserve the original bytes and any recorded integrity metadata |
| File pointer or omission notice | Include the actual file through the agreed delivery channel, or record it as missing |
| Internal object reference | Treat it as provenance, not a public URL or proof that the bytes were delivered |
| Truncated trace preview | Locate the complete retained observable evidence before claiming completeness |

Packaging or transfer-tool limits are separate from the API's upload limits.

If required bytes are unavailable, mark the delivery incomplete. Do not replace them with empty files, summaries, invented hashes, or broken download links.

## Preserve useful files, remove unrelated material

Keep native workbooks, documents, drawings, images, code, verifier output, and graded deliverables. An optional PDF or image preview does not replace the native artifact.

Exclude `.git/`, caches, OS sidecars, unrelated runs, credentials, and private reasoning from a delivery. Preserve authored files and task-required hidden configuration. Keep Oracle material and hidden tests protected from the model runtime.

## Use the right upload path

Document feedback accepts one document, not a large folder. Rollout analysis accepts a bounded JSON projection, not a raw archive.

For direct bundle submission:

1. Read `GET /api/v3/gdpx/capabilities` for current compressed, expanded, member, and chunk limits.
2. Build the [canonical API bundle](/gdpx/evaluation-bundle-upload#canonical-zip-layout), preserving exact task and evidence bindings.
3. Follow the returned resumable-upload relations and part limits.
4. Send only the supplied storage headers; never send the API key to storage.
5. Finalize and poll the durable submission resource.

Do not split a required task or attempt across incomplete bundles to evade a limit. Separate independent submissions only when the advertised contract permits it; otherwise arrange a supported transfer with Standard Data.

Keep signed upload URLs and internal storage references out of shared logs, documentation, and analysis requests.
